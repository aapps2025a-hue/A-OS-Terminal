# A-OS Terminal

<h2>Advantages</h2>
A terminal where you can do anything you want easily. No hard commands, no annoying Are You Sure poppups or anything like that.
--
<h2>What is it?</h2>
The A-OS terminal it a free, opensource python-based terminal that acts as a normal terminal, but it has a-os commands and only knows the branch after it is runned. Fell free to edit, share, comment and discuss. Run it on a .py file.  the os acts as where it is placed, is the root. You can run code and edit filles with a linux layout.
